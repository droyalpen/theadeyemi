# Adeyemi Adeyinka — Portfolio Website

A responsive, static HTML/CSS/JavaScript portfolio with a dark hero and light content sections.

## Files
- `index.html` — content and page structure
- `styles.css` — layout, responsive styling, and visual system
- `script.js` — mobile navigation, current year, and email-copy interaction

## Before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html` with your professional email address.
2. In `script.js`, replace `YOUR_EMAIL@example.com` with the same email address.
3. Replace the LinkedIn and GitHub URLs in `index.html` with your real profile URLs, or remove links you do not use.
4. Review all project summaries and metrics for accuracy and confidentiality.
5. Add a professional headshot or a downloadable CV if desired.

## Preview locally
Open `index.html` in a modern browser. The Google Fonts import needs an internet connection; the site otherwise works as a static website.

## Publish
You can host these files on GitHub Pages, Netlify, Cloudflare Pages, or another static web host. A custom domain can be connected later.
